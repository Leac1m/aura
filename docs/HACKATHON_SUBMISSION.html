Aura: Your Intent, Solana's Execution

DeFi Track Mobile Track AI Integration

1. Project Description

Tagline: The first voice-native agentic wallet bridging natural language to high-performance DeFi execution.

The Problem: Mobile Web3 is broken by "click-fatigue." Swapping, bridging, or staking on the go requires navigating multiple complex UIs and signing a dozen transactions. Users shouldn't have to be DeFi experts to manage their assets; they should just be able to state their goal.

The Solution: Aura is a mobile-first interface that replaces manual trading with Intent-Based Orchestration. Using a "Thin Client, Thick API" model, Aura converts natural voice commands into complex on-chain actions. Talk to Aura, and it handles the routing (via LI.FI), the security (via a custom Anchor Escrow), and the execution—all with a single user signature.

2. Key Features

  • Voice-to-Intent Pipeline: High-fidelity capture via ElevenLabs and reasoning via OpenAI/Anthropic to map vague goals ("Save my SOL") to technical actions ("Deposit into JitoSOL").
  • Autonomous Routing: Integration with LI.FI for optimal cross-dex pathfinding and slippage protection.
  • X402 Monetization: A novel payment protocol where advanced DeFi "Skills" (like MEV-protected routes) are gated behind micro-payments in SOL.
  • Secure Delegation: An Anchor-based escrow program that creates personal PDAs for users, allowing the agent to execute within strict, user-defined guardrails.

3. Technical Implementation

Frontend: React Native (Expo) with Solana Mobile Stack (SMS) and Mobile Wallet Adapter (MWA).

On-Chain: Anchor program implementing EscrowState with time-bound subscription proofs and allowance guardrails.

Infrastructure: Next.js App Router for the "Agent Brain," coordinating ElevenLabs (Voice), LLMs (Intent), and LI.FI (Routing).
